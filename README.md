# Novacrest Kft. – GitHub Pages

Statikus, Cloudflare nélküli weboldal. A Stripe fizetés később biztonságos Stripe Payment Linkekkel kapcsolható hozzá.

## Közzététel

1. A mappa tartalmát töltsd fel a GitHub repository `main` ágának gyökerébe.
2. GitHub: **Settings → Pages → Deploy from a branch**.
3. Válaszd a `main` ágat és a `/ (root)` mappát.
4. A Custom domain mezőben add meg: `novacrest.hu`.

Az oldal nem tartalmaz titkos Stripe API-kulcsot és nem igényel szerveroldali futtatást.
